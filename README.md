# Подход — дневник зала

Записываешь тренировки в зале: подходы, веса и время.

## Что умеет

- **Тренировки-шаблоны.** Название и список упражнений, например «Ноги и ягодицы».
- **Тренировка в зале.** Крупный таймер, подходы «вес × повторы» с галочкой, таймер отдыха после каждого подхода. Можно добавить подход или упражнение по ходу.
- **Память весов.** Перед стартом и во время тренировки видно, что было в прошлый раз и какой у тебя рекорд. Прошлые веса уже подставлены в поля, а когда побьёшь рекорд, приложение об этом скажет.
- **Прошедшие тренировки.** Можно записать задним числом: день, время начала, длительность и при желании подходы. Уже сохранённые тренировки можно исправить.
- **История.** Итоги месяца, дни недели, когда ты была в зале, график минут по дням за 30 дней и список тренировок по месяцам.

## Запуск

Это один файл `index.html` без сборки и зависимостей. Открой его в браузере или включи GitHub Pages (Settings → Pages → ветка `main`).

## Где хранятся данные

- В артефакте Claude данные синхронизируются между устройствами.
- При открытии с GitHub Pages или локально данные хранятся в браузере (`localStorage`) только на этом устройстве.
